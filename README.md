# GEPT 中級｜健康飲食單字大冒險

[開啟手機遊戲](https://carolchihsien-ship-it.github.io/word-adventure/)

題庫取自使用者提供的課本第 3–5 頁照片，含 35 個標示單字／片語，以及經使用者同意從例句補入的 fruit、vegetable、health、blood sugar、disease，共 40 項，搭配 13 句原文例句。

四組各十題：🥗飲食基礎、🌾纖維與消化、🥕營養與保護、🛡️免疫與健康。

- 🎧 聽力：先聽原文例句，再聽目標單字，四選一選中文。
- ✏️ 拼字：看中文與例句挖空，填入符合句子的字形；提示單複數、不規則複數與 -ing。
- 🎤 錄音：讀單字／片語供辨識計分，另提供完整例句聆聽與跟讀。例句跟讀不另計分。

每組完成自動儲存本機進度並同步老師表格，成功收到後端確認才顯示已存入。保留每組最高分，重新開始只清除本機該生進度。新版題庫與舊版進度、成績分開保存。

前端 GitHub Pages＋後端 Google Apps Script，沿用原有網址。老師端設定與後端原始碼留在老師本機，不公開管理連結或內部資源識別碼。

介面基於使用者提供的[成功範本](https://sharlicwu.github.io/word-link-game/)。請以支援語音辨識的手機瀏覽器直接開啟 HTTPS 遊戲頁，首次需要麥克風授權；不支援可使用自評。
