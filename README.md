# 單字大冒險

手機英文單字練習，包含聽力、拼字與錄音三關，每關四組、每組十題。

[開啟遊戲](https://carolchihsien-ship-it.github.io/word-adventure/)

目前沿用使用者提供的[成功範本](https://sharlicwu.github.io/word-link-game/)的 40 個生活單字。老師可修改 index.html 的 GAME_TITLE、WORDS 與 GROUPS。

每組完成會保留本機進度並自動同步；只有收到後端確認才顯示存入成功。共用手機可按「換一位同學」，依英文名字分開保存。重新開始僅清除該生本機進度，老師表格仍保留各組最高分。

錄音請直接使用支援語音辨識的瀏覽器開啟 HTTPS 遊戲頁；不支援的裝置可自評。初次使用需要麥克風授權。

前端採 GitHub Pages，後端採 Google Apps Script。老師端完整設定、後端原始碼與維護說明保留在老師的本機專案，不在公開儲存庫提供管理資訊。
